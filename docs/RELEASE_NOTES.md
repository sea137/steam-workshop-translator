海京Tools 0.3.5：离线服务错误提示、繁忙处理与启动排障。

本地服务没启动、超时、繁忙和模型推理失败现在分别提示，不再误导用户重新下载模型。连续请求不会继续排入模型队列，健康检查可正常响应；断开连接不会造成重复错误回复。修复 Windows 离线停止脚本只结束 Python 启动器、实际服务仍占端口的问题。

升级：退出 Steam 后运行 Install.cmd。已有模型的用户无需重装离线环境或重新下载模型；运行**新版包中的**「停止离线翻译.cmd」，再运行「启动离线翻译.cmd」，服务代码会更新并启动。

若安装后 Steam 无法打开：完全退出 Steam 后运行「停用海京Tools.cmd」，测试是否恢复。可用「恢复海京Tools.cmd」撤销停用。若仍不能启动，参照 docs/TROUBLESHOOTING.md 使用 Millennium 官方卸载方式继续隔离框架问题。不会删除游戏，不会自动卸载其他插件。玩家启动失败的具体根因仍需错误截图/日志确认。
