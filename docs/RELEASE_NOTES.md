海京Tools 0.3.6：本地翻译服务按需启动。

首次安装离线环境后，点击「本地模型 → 翻译本页」会自动检查服务；未运行时启动已安装的模型并等待就绪。电脑重启后不用再手动找启动脚本。不添加 Windows 开机项，不修改 DNS、hosts 或代理。

**升级必须运行新版 Install.cmd**，它会复制新的启动辅助文件。已有模型和私有环境保留，不需要重复下载模型；仅替换 .star 文件不能完成辅助文件升级。首次安装用户仍需运行「安装离线翻译.cmd」。

启动采用固定路径脚本、单实例和重复启动限制。前端等待期间可取消，选择在线来源不会启动本地模型。原生框架冷启动测试确认调用能返回；后台模型在调用方退出后仍可翻译。40 项前端测试与 Lua/LuaJIT 后端检查通过。

玩家反馈的 DNS_PROBE_FINISHED_NXDOMAIN 仅说明域名解析失败；在没有错误域名和隔离结果前，无法确定由海京Tools、Millennium、302 或网络环境中的哪一层引起。安装包保留可撤销停用脚本，详见 docs/TROUBLESHOOTING.md。
