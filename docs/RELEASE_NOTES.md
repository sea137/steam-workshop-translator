海京Tools 0.3.4：游戏库更新弹窗与逐段对照翻译。

- 游戏库内打开新闻/更新公告时，也会出现翻译面板；关闭后自动清理。
- 每个标题、段落、列表项的中文紧跟对应原文，完成一批就显示一批。
- 只翻译当前正在看的公告，跳过前后预加载的文章。
- 保留原始链接，点击「还原」恢复原文与原来的页面结构。

验证：36 项交互回归、实际发布插件的 Lua / LuaJIT 后端回归通过。真实 Steam 公告内容在 Chromium 中通过本地模型生成 28 段译文，首批结果在全文完成前显示，8 个链接和原始 DOM 还原检查通过；不将浏览器复现与 Steam 客户端人工验收混同。

普通玩家下载 **HaijingTools-v0.3.4-Windows-WithModel.zip**：完整解压 → 退出 Steam → Install.cmd → 安装离线翻译.cmd → 启动 Steam 并启用海京Tools。

完整包已附英中模型和内置词库，无需单独下载“题库”。第一次仍需联网下载缺少的 Millennium 框架与私有运行环境；以后重启电脑需运行「启动离线翻译.cmd」。已有模型不必重新下载，升级插件运行 Install.cmd 即可。

模型许可与详细步骤见仓库安装说明。
