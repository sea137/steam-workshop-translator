# 海京Tools 问题反馈说明

**遇到错误，请提供实际出错窗口截图和复现步骤。只有“打不开”“翻译不了”或错误文字搜索链接，通常无法定位。截图请保留完整报错，并遮住隐私。**

1. **截图**：尽量截完整 Steam 窗口，包含翻译面板的版本、翻译源、完整错误文字；截不到的信息用文字补充。
2. **页面**：出问题的工坊或新闻链接。DNS 报错请提供地址栏中的实际域名；B站生成的错误名搜索链接不能代替实际地址。
3. **步骤**：做了什么后出现、出现频率、最后正常的版本。例如“本地模型连续翻译三篇公告后失败”。
4. **环境**：Windows、Steam 正式版或测试版、Millennium 版本，是否使用 SteamCommunity 302、代理或加速器。

Steam 无法启动：说明“无窗口 / 闪退”还是“能打开但无法登录 / 联网失败”。有错误窗口就截图；完全无窗口就说明点击后发生了什么，不必为了截图反复启动崩溃程序。

本地服务启动失败：保留启动脚本窗口里的完整错误；需要日志时提供 `%LOCALAPPDATA%\HaijingTools\offline\server-error.log` 或 `on-demand-error.log` 相关片段。翻译失败不等于模型丢失，不必立即重新下载。

## 隐私与排障声明

- 截图和日志分享前，遮住账号、邮箱、个人路径中的姓名、订单和密钥。**不要提供密码、Cookie、验证码或完整登录凭据。**
- Steam 无法打开时，按 [排障说明](TROUBLESHOOTING.md) 可撤销停用本插件，保留信息，再逐层检查。
- 单凭 DNS 错误或“安装后打不开”不能确定原因，需要相同页面与停用前后的对照。不要直接删除 Steam、游戏或模型，也不要盲目修改 DNS、hosts。
