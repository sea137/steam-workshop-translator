# 0.2.0 性能记录

日期：2026-10-25。

旧版 24 个不同标题调用 24 次逐条 RPC。回归测试在旧版失败，升级后调用 3 次批量 RPC，生成全部 24 处译文。

优化：每批最多 8 段、批内去重、每批写一次缓存；可见内容优先，每批让出事件循环；减少原文重复扫描和目标元素两两比较。

批量结果严格检查编号、数量、顺序与结束标记，编号被改动时回退逐条翻译。服务失败时直接报错，不进行八次无效重试。

## 单次真联网样本

使用相同 Lua 后端代码，在独立 Lua 环境里调用真实 Google HTTPS 接口。8 条公开短文本，独立空缓存。测试 HTTP 适配器不等同于 Steam 原生传输计时。

| 场景 | 0.1.2 | 0.2.0 |
| --- | ---: | ---: |
| 冷缓存 HTTP 请求 | 8 | 1 |
| 总耗时 | 7.263 秒 | 0.717 秒 |
| 热缓存 HTTP 请求 | 0 | 0 |

该样本约快 10.13 倍。**不能据此承诺固定倍数，也没有测量 Steam 的界面帧率。** 长介绍、网络、语言、服务限流及回退都会影响实际速度。

验证包括类型检查、14 项 DOM/交互测试、Lua 批量编号和回退、去重、缓存、429/断网/异常响应，以及 Chromium 布局和对象响应回归。
